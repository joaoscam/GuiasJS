# Projeto: Tabs interativas com Temas de Times de Futebol ⚽

## 📌 Descrição
Este projeto é uma página web interativa que utiliza **HTML, CSS e JavaScript** para exibir abas (tabs) com descrições e imagens de diferentes times de futebol.  

Cada botão representa um time. Ao clicar:
- O conteúdo (texto e imagem) é atualizado dinamicamente.
- O tema da página muda (cores personalizadas por time).
- Apenas a aba selecionada permanece ativa.  

---

## 🖼️ Demonstração

Exemplo do funcionamento:  
- Clique em "Corinthians" → A página troca as cores para preto/branco/vermelho e mostra a descrição do time.  
- Clique em "Palmeiras" → O tema muda para verde, e a descrição e imagem do time aparecem.
